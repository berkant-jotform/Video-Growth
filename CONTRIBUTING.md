# Contributing

Read the README and applicable AGENTS.md instructions, then create a focused branch. Use synthetic examples and an isolated local environment. Run the checks listed in [the developer reference](docs/REFERENCE.md) that apply to your change.

Open a pull request explaining what changed, how you checked it and any remaining limits. Preserve original evidence, saved decisions, existing access controls and review/consent gates.

Use the bug or improvement issue form for non-sensitive reports. Remove credentials, access-bearing links, private exports and personal data from screenshots and logs. Report security issues privately as described in [SECURITY.md](SECURITY.md).
