# Downloads and installation

## Get the source

Open the repository, choose **Code → Download ZIP**, and extract it. If the repository is private, sign in with an account that already has access. A source ZIP contains the project files; it does not install Node.js, Python, native tools, provider keys or models.

Follow [Getting started](GETTING_STARTED.md) for this project. Keep the extracted folder somewhere you can find again. Do not launch directly from an archive preview.

## Large applications and models

Large installers, dependency folders, model weights and live user data are not attached here. Use the project-specific packaging instructions below when a build is needed. A successful build still needs the documented installation checks before being shared with colleagues.

## This project

The web app is configured separately for its database and approved source access. The Chrome source is in `extension/`; `npm run package-extension` creates a ZIP. Existing ZIPs in the repository are historical artifacts: check the app’s required extension version before using one.

## Sharing

This repository is public. Never attach credentials, private account exports or personal data to a release.
